# 💰 Expense Calculator

A simple and user-friendly web application that helps users track their expenses, calculate total spending, and manage their daily budget efficiently.

## 📌 About The Project

The **Expense Calculator** is a web-based application designed to make expense management simple and convenient. Users can add their expenses, view their spending, and calculate the total amount spent.

This project is suitable for anyone who wants a quick and easy way to keep track of their daily expenses.

## ✨ Features

* ➕ Add new expenses
* 💵 Calculate total expenses
* 📋 View expense records
* 🗑️ Remove expenses
* 📊 Simple and clean interface
* 📱 User-friendly design
* ⚡ Fast and easy to use

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript


3. Open `index.html` in your web browser.
